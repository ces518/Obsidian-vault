# Daily 주간 리뷰 / Knowledge 후보 추출 프롬프트

## 목적

최근 Daily 노트에서 반복 주제, Knowledge 후보, Project 실험 후보, Career 활용 자료를 추출한다.

## Prompt

```text
01_Daily 아래 최근 7일간의 데일리 노트를 분석해줘.

목표:
- 반복해서 등장한 주제
- Knowledge로 승격할 만한 개념
- 추가로 공부해야 할 질문
- Project 실험으로 남길 만한 내용
- 면접 답변으로 재활용 가능한 내용
을 찾아줘.

아직 파일 생성이나 수정은 하지 말고 보고서만 작성해줘.

결과 형식:
1. 반복 등장한 주제
2. Knowledge 문서 후보
3. Project 실험 후보
4. Career/interview 문서 후보
5. 아직 불명확한 질문 목록
6. 다음 주 학습 추천 순서

주의:
- Daily에 없는 내용을 추측하지 마.
- 사용자의 표현과 관심사를 최대한 유지해.
- 실제 파일 생성/수정은 승인 후 진행해.
```
