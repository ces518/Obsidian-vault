# 중복 문서 탐지 프롬프트

## 목적

주제가 겹치는 문서, 병합 후보, 이름 변경 후보를 찾는다.

## Prompt

```text
03_Knowledge 아래에서 주제가 중복되거나 내용이 겹치는 문서를 찾아줘.

결과는 다음 형식으로 정리해줘:
1. 중복 후보 그룹
2. 각 문서의 현재 역할
3. 유지할 대표 문서
4. 병합 후보
5. 이름 변경 후보
6. Archive로 보낼 후보
7. 판단이 어려운 문서

규칙:
- 아직 실제 수정은 하지 마.
- 문서 삭제는 제안하지 말고 Archive 이동만 제안해.
- 병합이 필요한 경우 병합 후 목차를 먼저 제안해.
- Obsidian 내부 링크가 깨질 가능성이 있으면 표시해.
- 사용자의 기존 표현이나 비유가 들어간 문서는 보존 우선으로 판단해.
```
