# 기존 Concept 문서 리팩토링 프롬프트

## 목적

이미 작성된 Knowledge 문서를 LLM Wiki 형식에 맞게 보강한다.

## Prompt

```text
다음 Knowledge 문서를 concept-note 형식에 맞게 리팩토링해줘.

대상 문서:
- [여기에 파일 경로 입력]

요구사항:
1. 기존 내용과 사용자의 설명 스타일은 최대한 유지해.
2. 문서 상단에 YAML Properties가 없다면 추가해.
3. 제목이 모호하면 검색 가능한 제목을 제안해.
4. 아래 섹션이 없으면 필요한 것만 추가해:
   - 개요
   - 한 줄 요약
   - 왜 필요한가
   - 핵심 개념
   - 예시
   - 실무에서 주의할 점
   - 헷갈리기 쉬운 점
   - 면접식 설명
   - 관련 문서
5. 중복 설명은 정리하되, 의미를 바꾸지 마.
6. 원문에 없는 내용은 단정하지 마.
7. 불확실한 내용은 "확인 필요:"로 표시해.
8. 작업 전 변경 계획을 먼저 보여줘.
9. 내가 승인하기 전까지 파일을 수정하지 마.
```
