# Inbox → Knowledge → MOC 전체 플로우 프롬프트

## 목적

작은 규모의 Inbox 정리를 한 번에 진행하되, 안전하게 계획 승인 단계를 포함한다.

## Prompt

```text
00_Inbox/to-refine 아래 문서들을 대상으로 LLM Wiki 정리 플로우를 진행해줘.

진행 단계:
1. 문서 분석
2. Study / Knowledge / Project / Career 분류
3. 이동/생성/수정 계획 작성
4. 관련 MOC 업데이트 계획 작성
5. 내가 승인하면 실제 작업 진행

중요:
- 지금은 1~4단계까지만 수행해.
- 내가 "진행해"라고 말하기 전까지 실제 파일 수정, 이동, 삭제는 하지 마.

분류 기준:
- 02_Study: 책/강의/스터디 흐름을 보존해야 하는 원천 메모
- 03_Knowledge: 독립적으로 재사용 가능한 개념 문서
- 04_Projects: 직접 실험/구현/테스트 기록
- 05_Career: 면접/이력서/커리어 활용 자료
- 00_Inbox/to-refine: 아직 판단 어려움

결과 형식:
1. 문서별 분류표
2. 이동 계획
3. 생성할 Knowledge 문서
4. 수정할 기존 문서
5. 업데이트할 MOC
6. 보류할 문서
7. 승인 요청
```
