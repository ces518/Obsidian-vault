# 승인 후 실제 정리 프롬프트

## 목적

분석과 계획을 확인한 뒤, 승인한 항목만 실제로 정리한다.

## Prompt

```text
좋아. 위 정리 계획 중 내가 승인한 항목만 진행해줘.

작업 규칙:
1. 문서 삭제는 하지 마.
2. 승인하지 않은 파일은 수정하지 마.
3. 기존 raw 문서는 필요한 경우 02_Study 또는 00_Inbox/to-refine에 남겨.
4. 새 Knowledge 문서는 concept-note 형식으로 작성해.
5. 문서 상단에는 YAML Properties를 추가해.
6. Obsidian 내부 링크는 [[문서명]] 형식으로 작성해.
7. 원문에 없는 내용은 추측하지 말고 "확인 필요:"로 표시해.
8. 대량 리네이밍은 하지 마.
9. 작업 후 변경된 파일 목록과 요약을 알려줘.

보고 형식:
1. 생성된 파일
2. 수정된 파일
3. 이동된 파일
4. 삭제된 파일 여부
5. 확인 필요로 남긴 항목
6. 다음에 해야 할 작업
```
