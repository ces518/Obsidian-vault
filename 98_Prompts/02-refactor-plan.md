# 정리 계획 수립 프롬프트

## 목적

Inbox 분석 결과를 바탕으로 실제 정리 전에 이동/생성/수정 계획을 받는다.

## Prompt

```text
위 분석 결과를 바탕으로 정리 계획을 만들어줘.

아직 파일은 수정하지 말고, 다음 형식으로 계획만 작성해줘.

1. 이동할 파일 목록
   - 기존 경로
   - 새 경로
   - 이동 이유

2. 새로 생성할 Knowledge 문서 목록
   - 문서 제목
   - 생성 경로
   - 원본 참고 문서
   - type / area / status

3. 수정할 기존 문서 목록
   - 수정 이유
   - 추가할 내부 링크
   - 추가할 섹션

4. 업데이트할 MOC 목록
   - MOC 파일명
   - 추가할 링크

5. 애매해서 보류할 문서
   - 이유
   - 추가로 확인할 질문

주의:
- 아직 실제 파일 이동/수정/삭제는 하지 마.
- 삭제 대신 Archive 또는 Inbox 유지로 제안해줘.
- Obsidian 링크가 깨질 수 있는 이동은 별도 표시해줘.
```
