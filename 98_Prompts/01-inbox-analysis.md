# Inbox 분석 프롬프트

## 목적

`00_Inbox`에 쌓인 raw 메모를 바로 정리하지 않고, 먼저 어디로 보내야 할지 분석한다.

## Prompt

```text
00_Inbox 아래 문서들을 분석해줘.

목표:
- 각 문서가 Study 원천 메모인지, Knowledge로 승격할 개념인지, Project 실험 기록인지, Career 자료인지 분류해줘.
- 아직 실제 파일 이동이나 수정은 하지 마.
- 결과는 표로 보여줘.

분류 기준:
- 02_Study: 책/강의/스터디 흐름을 따라가는 원천 메모
- 03_Knowledge: 독립적으로 재사용 가능한 정제 지식 후보
- 04_Projects: 직접 실험/구현/코드 테스트 기록
- 05_Career: 면접/이력서/커리어에 활용할 자료
- 00_Inbox/to-refine: 아직 판단이 어려운 문서

각 문서마다 다음을 알려줘:
1. 현재 파일명
2. 추천 위치
3. 추천 문서 타입
4. 추천 제목
5. Knowledge 승격 가능 여부
6. 필요한 관련 링크 후보
7. 수정 전 주의사항

주의:
- 파일 이동, 수정, 삭제는 하지 마.
- 문서 내용을 과도하게 해석하지 마.
- 원문에 없는 내용은 추측하지 마.
```
