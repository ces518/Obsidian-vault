# Knowledge → 면접 자료 생성 프롬프트

## 목적

`03_Knowledge` 문서를 기반으로 `05_Career/interview`에 면접 질문/답변 초안을 만든다.

## Prompt

```text
03_Knowledge 문서들을 기반으로
05_Career/interview에 백엔드 개발자 면접 질문과 답변 초안을 만들어줘.

범위:
- Java
- DB
- Network
- MQ
- System Design
- Performance
- Testing

규칙:
1. 답변은 내 문서에 있는 내용을 우선으로 작성해.
2. 각 답변 아래에 참고한 Obsidian 링크를 추가해.
3. 모르는 내용은 추측하지 말고 "보강 필요:"로 표시해.
4. 단순 암기 답변보다 실무형 설명으로 작성해.
5. 내가 직접 설명할 수 있는 말투로 정리해.
6. 기존 interview 문서가 있으면 새로 만들기보다 업데이트 후보로 제안해.
7. 작업 전 생성/수정 계획을 먼저 보여줘.
8. 내가 승인하기 전까지 파일을 수정하지 마.

결과 형식:
1. 생성/수정할 파일
2. 질문 목록
3. 참고할 Knowledge 문서
4. 보강이 필요한 주제
```
