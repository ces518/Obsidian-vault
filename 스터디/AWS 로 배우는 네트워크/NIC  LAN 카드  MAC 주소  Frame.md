
## 개요

OSI 7 Layer의 **L2(데이터 링크 계층)** 수준에서 알아야 할 핵심 개념들을 다룬다.
**NIC**, **MAC 주소**, **Frame**, **LAN**의 개념과 Ethernet 헤더 구조까지 정리한다.

---

## 1. OSI 7 Layer 학습 범위

| 계층 | 다루는 내용 | 비고 |
|------|-----------|------|
| **L1** (물리) | 케이블 규격, 전기 신호 등 | ❌ 다루지 않음 |
| **L2** (데이터 링크) | NIC, MAC 주소, Frame | ✅ 핵심 |
| **L3** (네트워크) | IP, 패킷 | ✅ 핵심 |
| **L4** (전송) | TCP/UDP, 세그먼트 | ✅ 핵심 |
| **L5** (세션) | TLS/SSL, 암호 기술 | △ 간단히 언급 |
| **L7** (응용) | HTTP, HTTPS | ✅ 상세히 다룸 |

> [!note] HTTPS = HTTP + SSL
> - AWS 환경에서 웹 서비스 개발 시 **HTTPS 통신은 기본**
> - SSL 인증서 발급, 암호화 트래픽 처리 등이 관련됨

> [!tip] 학습 순서
> OSI 7 Layer에서 **아랫집은 윗집의 존립 기반**이므로, L2 → L3 → L4 순서로 아래에서 위로 쌓아 올리며 공부한다.

## 2. NIC (Network Interface Card)

> [!important] 정의
> **NIC** = Network Interface Card (흔히 "랜카드"라 부르지만, **NIC**가 전문 용어)

### NIC의 두 종류

| 구분 | 규격 | 표준 기관 |
|------|------|----------|
| **유선** | Ethernet | IEEE |
| **무선** | IEEE 802.11x (Wi-Fi) | IEEE 802.11 위원회 |

- **802.11x**에서 `x`는 버전을 뜻함 (a, b, g, n, ac, ax …)
- 현재는 **Wi-Fi 7** 시대 — 무선 전송 속도가 수십 Gbps에 달해 유선에 근접
- **IEEE** = 전기전자 기술자 협회, `802.11`은 무선 네트워크를 다루는 위원회 번호

## 3. MAC 주소 (MAC Address)

> [!important] 정의
> **MAC 주소** = NIC(하드웨어)에 부여된 **48비트 고유 식별자**
> 전 세계에서 유일(Unique)한 값

### 같은 말, 다른 이름

| 용어 | 의미 |
|------|------|
| **MAC Address** | Media Access Control 주소 |
| **하드웨어 주소** | 하드웨어(NIC)에 부여된 주소 |
| **물리 주소** | Physical Address |

> 셋 다 **같은 것**을 가리킨다.

### MAC 주소 구조 (48비트 = 6바이트)

```
  00 - 50 - 56 - C0 - 00 - 01
  ├──────────┤   ├──────────┤
   앞 3바이트      뒤 3바이트
   (OUI)          (고유 번호)
   = 제조사 정보    = 장치 개별 식별
```

- 16진수 한 자리 = **4비트**, 두 자리 = **8비트(1바이트)**
- 앞 3바이트(OUI)를 읽으면 **제조사 정보**를 알 수 있음 (Apple, Samsung 등)

### MAC 주소 변경 가능 여부

> [!warning] MAC 주소는 변경 가능하다
> - 칩에 새겨진 원본 값 자체는 수정 불가
> - 하지만 **소프트웨어적으로 덮어쓰기(변경) 가능**
> - 변경된 MAC 주소 → **Virtual MAC Address**

#### Virtual MAC이 필요한 이유

무선 네트워크(Wi-Fi) 접속 시 MAC 주소가 노출되면 → 앞 3바이트로 **제조사(기기 정보) 파악 가능** → **보안 문제** 발생

→ 접속할 때마다 MAC 주소를 변경하여 추적을 방지

### MAC 주소 vs IP 주소

| 구분 | MAC 주소 | IP 주소 |
|------|---------|---------|
| **계층** | **L2** (데이터 링크) | **L3** (네트워크) |
| **크기** | 48비트 | 32비트 (IPv4) |
| **유일성** | 전 세계 유일 | 인터넷에서 유일 |
| **용도** | LAN 내 장치 식별 | 인터넷 통신 |

> [!caution] MAC 주소로 인터넷을 쓸 수 없는 이유
> MAC 주소는 L2에서만 의미가 있고, 인터넷(IP)은 L3이다.
> **속한 계층(세상) 자체가 다르다.**

## 4. LAN (Local Area Network)

> [!important] 정의
> **LAN** = 공유기(라우터) 안쪽의 로컬 네트워크 구간

```
┌─────────────── LAN 구간 ───────────────┐
│                                         │
│  [PC]  [태블릿]  [스마트폰]              │
│    │      │         │                   │
│    └──────┼─────────┘                   │
│           │                             │
│      ┌────▼────┐                        │
│      │ 공유기   │ ← 경계 장치            │
│      └────┬────┘                        │
└───────────┼─────────────────────────────┘
            │
     ┌──────▼──────┐
     │   Internet   │  ← Public 구간 (ISP: SK, KT, U+)
     │  (L3 이상)   │
     └─────────────┘
```

- **LAN 안쪽** = 우리 집 내부 (Private, Local)
- **LAN 바깥** = 인터넷 구간 (Public)
- 공유기 = LAN과 인터넷의 **경계 장치**

## 5. Ethernet Frame 헤더 구조

L2에서 유통되는 데이터 단위 = **Frame**

> L2라는 말이 나오면 → **Frame** / Frame이라는 말이 나오면 → **L2**

### 헤더 구성

```
┌──────────────────┬──────────────────┬────────┬─────────────┐
│ Destination MAC  │   Source MAC     │  Type  │   Data ...  │
│    (48bit)       │    (48bit)       │(16bit) │  (Payload)  │
└──────────────────┴──────────────────┴────────┴─────────────┘
     목적지 MAC          출발지 MAC      타입       데이터
```

| 필드 | 크기 | 설명 |
|------|------|------|
| **Destination MAC** | 48비트 (6바이트) | 목적지 MAC 주소 |
| **Source MAC** | 48비트 (6바이트) | 출발지 MAC 주소 |
| **Type** | 16비트 (2바이트) | 뒤따르는 데이터의 해석 방식 결정 |

> [!example] Type 값 예시
> `0x0800` → 뒤에 오는 데이터가 **IP 패킷**임을 의미

## 6. 네트워크 확인 명령어

| OS | 명령어 | 설명 |
|----|--------|------|
| **Windows** | `ipconfig /all` | IP 설정 + 하드웨어(MAC) 정보 확인 |
| **Linux** | `ip addr` | 네트워크 인터페이스 정보 확인 |

## 핵심 요약

> [!summary]
> 1. **NIC** = Network Interface Card (유선: Ethernet / 무선: IEEE 802.11x)
> 2. **MAC 주소** = NIC에 부여된 **48비트 고유 식별자** (= 하드웨어 주소 = 물리 주소)
> 3. MAC 주소는 **소프트웨어적으로 변경 가능** → Virtual MAC Address (보안 목적)
> 4. MAC 주소 앞 3바이트 = **제조사(OUI)** 정보
> 5. **MAC은 L2, IP는 L3** — 속한 계층이 다르므로 MAC으로 인터넷 통신 불가
> 6. **LAN** = 공유기 안쪽 로컬 구간 / 바깥 = 인터넷(Public) 구간
> 7. **Frame** = L2의 데이터 단위 (Ethernet 헤더: 목적지 MAC + 출발지 MAC + Type)
