## 개요

네트워크를 학습하기 위한 기초 상식으로, **Host**의 개념과 네트워크 구성 요소의 역할 구분을 다룬다.

---

## 1. Host란?

> [!important] 정의
> **Host = 인터넷에 연결된 컴퓨터**

- 컴퓨터는 목적에 따라 게임기, 타자기, 학습 도구 등 다양한 정체성을 가진다
- 그 컴퓨터가 **네트워크에 연결되는 순간**, 우리는 이를 **Host**라고 부른다
- 여러 Host가 연결되면 **관계**가 형성되고, **통신(정보 교환)** 이 발생한다

### 프로토콜(Protocol)

- Host 간 통신 시 정보의 **형식**이 일치해야 서로 알아들을 수 있다
- 이 약속된 형식을 **프로토콜(Protocol)** 이라 한다

---

## 2. 인터넷이란?

> [!note] 인터넷 = 라우터(Router)의 거대한 집합체
> 전 세계를 아우르는 대규모 네트워크이며, 핵심 구성 요소는 **라우터**이다.

- 미국 DARPA에서 시작된 네트워크 규격
- 자력으로 라우터를 만든 나라: **1위 미국**, **2위 대한민국** (1980년대, 전길남 박사)

---

## 3. 네트워크의 두 가지 구성 요소

```
┌─────────────────────────────────────────────────┐
│               네트워크 (Internet)                 │
│                                                   │
│   ┌─────────┐    ┌─────────┐    ┌─────────┐     │
│   │ Router  │────│ Switch  │────│Firewall │     │
│   └─────────┘    └─────────┘    └─────────┘     │
│         네트워크 자체를 이루는 것 (Switch)          │
└────────┬──────────────────────────────┬──────────┘
         │                              │
    ┌────▼────┐                    ┌────▼────┐
    │   PC①   │                    │   PC②   │
    │(Client) │                    │(Server) │
    └─────────┘                    └─────────┘
      네트워크 이용 주체 (Endpoint)
```

### ① Endpoint (이용 주체)

- 네트워크를 **이용하는** 쪽 = **단말기**
- 5G 네트워크의 스마트폰, 인터넷에 연결된 PC 등
- 대표적인 Endpoint 역할:

| 역할 | 설명 |
|------|------|
| **Client** | 서비스를 **이용**하는 컴퓨터 |
| **Server** | 서비스를 **제공**하는 컴퓨터 |
| **Peer** | Client/Server 구분 없이 대등한 관계 |

### ② Switch (네트워크 인프라)

- 네트워크 **자체를 이루는** 장치 = 스위칭을 수행
- 종류:

| 장치 | 설명 |
|------|------|
| **Router** | 인터넷의 핵심 장치, 패킷 경로 결정 |
| **L2~L7 Switch** | 계층별 스위칭 장치 |
| **Firewall** | 보안 스위치 |

---

## 4. Switch도 Host가 될 수 있다

> [!example] 공유기(ipTIME) 사례
> - 공유기의 본질은 **Switch** (Public IP 주소를 공유하여 여러 단말기가 인터넷 사용)
> - 하지만 공유기가 **자동 업데이트**를 위해 스스로 인터넷에 접속할 때는 → **Host(Endpoint)** 역할
> - 즉, Switch도 네트워크 이용 주체로 참여하면 **Host가 될 수 있다**

### 공유기의 본질

- ISP(인터넷 서비스 프로바이더)가 제공하는 **Public IP 주소는 1개**
- 공유기는 이 1개의 IP를 **여러 단말기가 공유**할 수 있게 해주는 장치

---

## 핵심 요약

> [!summary]
> 1. **Host** = 인터넷에 연결된 컴퓨터 (통상적으로 Endpoint를 지칭)
> 2. **Endpoint** = 네트워크 이용 주체 (= 단말기) → Client, Server, Peer
> 3. **Switch** = 네트워크 자체를 이루는 장치 → Router, L2~L7 Switch, Firewall
> 4. **인터넷** = Router의 거대한 집합체
> 5. **프로토콜** = Host 간 통신의 약속된 형식
> 6. Switch도 네트워크를 이용하는 기능이 있으면 **Host 역할을 겸할 수 있다** (광의의 Host)
