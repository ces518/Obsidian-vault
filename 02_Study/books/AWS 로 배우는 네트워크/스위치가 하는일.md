# 스위치가 하는일

## 출처

- AWS 로 배우는 네트워크 (책)

---

## 핵심 내용

네트워크의 핵심 구성 요소인 **스위치(Switch)** 가 하는 일과 그 판단 근거를 다룬다.

---

### 1. 스위치가 하는 일 = 스위칭(Switching)

> [!important] 정의
> **스위칭 = 단위 데이터를 전달할 인터페이스(경로)를 선택하는 것**

- 스위치는 네트워크의 **중계기** 역할을 한다
- 데이터가 도착하면 **목적지에 도달하기 위한 최적의 경로**를 선택한다
- 모든 선택에는 **판단 근거**가 있으며, 그 근거에 따라 스위치의 종류가 결정된다

### 도로망 비유

```
출발지(A)                                    목적지(B)
  [Endpoint]                                [Endpoint]
      │                                         ▲
      ▼                                         │
   ┌──────┐     ┌──────┐     ┌──────┐     ┌──────┐
   │ ①번  │────▶│ ④번  │────▶│ ②번  │────▶│      │  ← 우회 경로
   │교차로 │     │교차로 │     │교차로 │     │      │
   └──────┘     └──────┘     └──────┘     │  B   │
      │                                    │      │
      └──────────▶┌──────┐───────────────▶│      │  ← 직진 경로
                  │ ③번  │                └──────┘
                  │교차로 │
                  └──────┘
```

- **교차로** = 스위치 (경로를 선택하는 지점)
- **도로** = 네트워크 (데이터가 이동하는 경로)
- **자동차** = 단위 데이터

---

### 2. 스위치의 판단 근거 — 테이블

스위치는 **테이블(Table)** 을 기반으로 경로를 선택한다.

| 테이블 종류 | 근거 정보 | 스위치 계층 |
|------------|----------|-----------|
| **MAC Address Table** | MAC 주소 | L2 스위치 |
| **Routing Table** | IP 주소 (구간별 그룹) | L3 스위치 / 라우터 |

> [!note] 라우팅 테이블
> - IP 주소를 하나하나 등록하는 것이 아니라, **구간(대역) 단위**로 묶어서 관리
> - "어디로 라우팅한다" = 스위치가 경로를 선택했다는 의미
> - **AWS에서도 라우팅 테이블 개념이 핵심적으로 등장**한다

### 4. 스위치의 계층별 분류 (L2 ~ L7)

판단 근거가 **OSI 7 Layer의 어느 계층 정보냐**에 따라 스위치 종류가 나뉜다.

```
L7 스위치  ← 가장 비쌈 / 가장 넓은 커버 범위
L6 ┆
L5 ┆  상위 스위치는 하위 스위치의 기능을 대부분 포함
L4 ┆
L3 ┆
L2 스위치  ← 가장 저렴
```

> [!tip] 상위 ⊃ 하위
> 상위 계층 스위치는 하위 계층 스위치의 기능을 **대부분 포함**한다.
> (항상 100%는 아니지만, 개념적으로 그렇게 이해해도 무방)

### 스위치의 종류

| 장치 | 설명 |
|------|------|
| **L2 ~ L7 스위치** | 계층별 스위칭 장치 |
| **라우터 (Router)** | 인터넷의 핵심, IP 기반 경로 선택 |
| **방화벽 (Firewall)** | 보안 스위치 |

---

### 5. 비용(Cost)과 경로 선택

스위치가 경로를 선택할 때는 **비용(Cost)** 도 고려한다.

| 비용 요소 | 설명 | 비유 |
|----------|------|------|
| **거리** | 물리적/논리적 경로 길이 | 시내 2km vs 우회 3.5km |
| **속도(대역폭)** | 네트워크 전송 속도 | 1Mbps vs 10Gbps |
| **소요 시간** | 실제 데이터 도달 시간 | 시내 20분 vs 고속도로 5분 |

> [!example] 내비게이션 비유
> 거리가 짧아도(시내 통과) 느릴 수 있고, 돌아가더라도(고속도로) 빠를 수 있다.
> 네트워크도 마찬가지로, **1Mbps 가까운 경로**보다 **10Gbps 먼 경로**가 훨씬 효율적이다.

---

## 이해한 내용

> [!summary]
> 1. **스위칭** = 단위 데이터를 전달할 **인터페이스(경로)를 선택**하는 것
> 2. 선택의 판단 근거는 **테이블**(MAC Address Table, Routing Table 등)에 기반
> 3. 근거 정보가 OSI 어느 계층이냐에 따라 **L2 ~ L7 스위치**로 분류
> 4. 상위 스위치는 하위 스위치의 기능을 **대부분 포함** (L7 ⊃ L6 ⊃ … ⊃ L2)
> 5. 경로 선택 시 **비용(거리, 속도, 소요 시간)**을 종합적으로 고려
> 6. **라우팅** = 스위치가 경로를 선택하는 행위 (AWS에서도 핵심 개념)

---

## 질문 / 헷갈리는 점

- 확인 필요: 라우팅을 넓게 보면 경로 선택 행위로 설명할 수 있지만, 엄밀하게는 L3의 IP 기반 경로 선택과 L2 스위칭을 구분해서 이해해야 한다.
- 확인 필요: "방화벽 = 보안 스위치"라는 표현은 책의 학습 흐름에서는 유용하지만, 실제 장비 분류에서는 방화벽과 스위치를 동일시하지 않도록 주의해야 한다.
- 확인 필요: 상위 계층 스위치가 하위 계층 기능을 대부분 포함한다는 설명은 개념적 이해용이며, 실제 제품 구현에서는 예외가 있을 수 있다.

## Knowledge로 승격할 후보

- `스위칭과 스위치의 판단 근거`: 스위칭을 "인터페이스 선택"으로 이해하는 기본 개념
- `MAC Address Table과 Routing Table 비교`: L2와 L3의 판단 근거 차이
- `L2-L7 스위치 분류`: OSI 계층별 스위치 구분과 실무 장비 이해
